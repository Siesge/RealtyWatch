# RealtyWatch

Портативный инструмент для анализа рынка квартир в Ялте. Собирает объявления с ЦИАН, Авито и Яндекс Недвижимости.

- `Parser App/`: само приложение (портативное: среда, браузер и база лежат внутри папки)
- `GeoZone_v1.jpg`: целевая зона поиска (красный круг)

## Фильтры по умолчанию

Квартира, 1–3 комнаты, от 40 м², 8–13 млн ₽, без обременения, не доля, не аукцион, с ремонтом.
