# RealtyWatch

Портативный инструмент для анализа рынка квартир в Ялте. Собирает объявления с ЦИАН, Авито и Яндекс Недвижимости.

## Быстрый старт (Windows)

1. Откройте папку `Parser App` и запустите **`RealtyWatch.exe`** (или `start.bat`). При первом запуске и после обновлений в папку сами доустановятся Python 3.12, библиотеки и Chromium (~400 МБ). `setup.bat` остаётся для ручной переустановки.
2. Откроется окно программы. Нужен WebView2 Runtime, он уже есть в Windows 11. `RealtyWatch.exe` — маленький запускатор с иконкой, его исходник лежит в `launcher/`, пересобрать можно через `launcher\build.bat`.
3. Выберите сайты и нажмите «▶ Запустить». Закрытие окна корректно останавливает текущие прогоны.

Для отладки: `runtime\python\python.exe -m app.main --server` запускает только сервер на http://127.0.0.1:8765/, без окна.

Всё хранится внутри `Parser App`, поэтому папку можно скопировать на флешку или другой компьютер вместе с базой.

| Папка | Что там |
|---|---|
| `app/` | код приложения |
| `web/` | интерфейс |
| `runtime/` | встроенный Python (создаётся `setup.bat`) |
| `browsers/` | Chromium (создаётся `setup.bat`) |
| `database/` | **вся база**: `realty.db`, фото `images/`, настройки поиска `settings.json`, резервные копии `backups/` |
| `data/` | служебное для этого компьютера (кэш окна, блокировка второго запуска) |
| `profiles/` | профили браузера и cookies для каждого сайта (не переносятся экспортом) |
| `logs/` | журнал `app.log` |

## Как собираются данные

| Сайт | Источник данных | Способ |
|---|---|---|
| ЦИАН | JSON API поиска | HTTP; браузер как запасной вариант |
| Яндекс | `INITIAL_STATE` страницы выдачи | HTTP; браузер как запасной вариант |
| Авито | HTML выдачи + страница объявления (координаты, ремонт) | браузер (HTTP блокируется) |

Режим `auto`: сначала быстрый HTTP с отпечатком Chrome (curl_cffi). Если сайт его блокирует, парсер переходит на стелс-Chromium (patchright) с постоянным профилем. Если сайт показывает капчу, её нужно пройти вручную в открытом окне браузера, а в журнале появится предупреждение ⚠.

## Экраны

- **Дашборд** (открывается при запуске). Сводка рынка: число объектов, медианы цены и цены м², новые, снятые объявления и изменения цен. Графики по каждой проверке: цены по комнатности, цена м² по зонам, движение рынка, предложение; у каждого графика есть табличный вид. Ниже — срез по комнатности и зонам, источники, самые выгодные предложения и сводка по избранному.
- **Подборка, Таблица, Карта.** Объекты с фильтрами. Клик по карточке открывает окно объекта с графиком цен по каждому сайту. Клик по строке таблицы открывает карточку в подборке.
- **Изменения.** Новые, снятые, вернувшиеся объявления и изменения цен, плиткой на объект, с разбивкой по сайтам. Первичная загрузка сайтов изменениями не считается.

## Автообновление и трей

Под переключателями сайтов включается «Автообновление каждые N часов» (1, 3, 6, 8, 12 или своё число), рядом идёт обратный отсчёт. Свернутое окно уходит в трей, сбор продолжается. После сбора приходит уведомление Windows, только если на рынке что-то изменилось; клик по нему открывает «Изменения».

## Снятие с продажи

Объявление считается снятым только после полного прохода выдачи. ЦИАН и Яндекс сначала проверяют такое объявление на его странице на сайте (ЦИАН показывает одну и ту же квартиру от разных агентов в поиске одним объявлением, поэтому отсутствия в поиске недостаточно). Объявление Авито снимается, если его нет в двух полных прогонах подряд. Причина снятия видна в подсказке на перечёркнутом объявлении. Кнопка «Перепроверить снятые» в настройках возвращает ошибочно снятые.

## Объекты и дубли

Одна и та же квартира на разных сайтах (и от разных агентов на одном сайте) объединяется в один объект прямо во время сбора. Объявления считаются одним объектом, если:

- совпадают комнаты, этаж и этажность дома;
- площадь отличается не больше чем на 1 м²;
- цена отличается не больше чем на 10%;
- расстояние между точками не больше 150 м. Если у одного из объявлений нет координат (у Авито — пока не открыта страница объявления), вместо этого должен совпасть адрес «улица + дом»;
- в новостройке не различаются номера квартиры или корпуса в описании; два объявления одного сайта в новостройке объединяются только при совпадающем номере квартиры.

Объявление присоединяется к объекту, только если совпадает по характеристикам со **всеми** его объявлениями, а не с одним, чтобы цепочки похожих квартир одной планировки не склеивались. Пометка дублей Яндекса (`clusterId`) используется только для поиска кандидатов. Карточка показывает объект и ссылки на каждое его объявление с ценой.

## Фото, избранное, перенос базы

- Главное фото каждого объявления хранится в `database/images/`. Недогруженные фото повторно загружаются после каждого сбора, при запуске программы и по кнопке «Догрузить фото» в настройках.
- ♥ на карточке добавляет объект в избранное. Фильтр «Избранное» находится в панели фильтров.
- «Настройки → База данных → Экспорт…» сохраняет всю базу одним `.zip`. «Импорт…» на другом устройстве либо **объединяет** базы (новое добавляется, по общим объявлениям берётся более свежая версия), либо **заменяет** базу целиком. Перед импортом текущая база сохраняется в `database/backups/`.

## Зоны

- **A**: красный круг с `GeoZone_v1.jpg` (центр 44.48382, 34.14335, радиус 1035 м)
- **B**: остальной город Ялта
- **C**: посёлки Большой Ялты (Ливадия, Массандра, Кореиз, Гурзуф…)

Объявления за пределами Ялтинского округа (сайты подмешивают Алушту и Партенит) отсеиваются. Границы города и округа взяты из OpenStreetMap (`app/yalta_city.json`, `app/yalta_district.json`).

## Фильтры по умолчанию

Квартира, 1–3 комнаты, от 40 м², 8–13 млн ₽, без обременения, не доля, не аукцион, с ремонтом. Меняются на вкладке «Настройки». Отсеянные объявления не удаляются: их можно посмотреть с фильтром «Статус → отсеянные» вместе с причиной отсева.
