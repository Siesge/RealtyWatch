# RealtyWatch

Портативный инструмент для анализа рынка квартир в Ялте. Собирает объявления с ЦИАН, Авито и Яндекс Недвижимости.

## Быстрый старт (Windows)

Готовый переносной архив `RealtyWatch-portable-<дата>.zip` (около 600 КБ) содержит только программу: распакуйте его в любую папку и запустите `RealtyWatch.exe` — остальное скачается само при первом запуске (нужен интернет). Подробности — в файле «Как запустить.txt» внутри архива.

Архивы собираются из корня репозитория: `"Parser App\runtime\python\python.exe" release\make_release.py` — только программа, из последнего коммита; с ключом `--with-db` — ещё и база: `RealtyWatch-с-базой-<дата>.zip` с `database/realty.db` (согласованный снимок, можно собирать при работающей программе), настройками и фотографиями. Такой архив на новом компьютере распаковывают и запускают: квартиры, история цен и фотографии уже на месте, импортировать ничего не нужно, скачается только Python с Chromium. Профили браузера с cookies не попадают ни в один архив — они привязаны к устройству.

1. Откройте папку `Parser App` и запустите **`RealtyWatch.exe`** (или `start.bat`). При первом запуске и после обновлений в папку сами доустановятся Python 3.12, библиотеки и Chromium (скачивается около 350 МБ, на диске около 700 МБ). `setup.bat` остаётся для ручной переустановки.
2. Откроется окно программы. Нужен WebView2 Runtime, он уже есть в Windows 11. `RealtyWatch.exe` — маленький запускатор с иконкой, его исходник лежит в `launcher/`, пересобрать можно через `launcher\build.bat`.
3. Выберите сайты и нажмите «▶ Запустить». Закрытие окна корректно останавливает текущие прогоны.

Для отладки: `runtime\python\python.exe -m app.main --server` запускает только сервер на http://127.0.0.1:8765/, без окна.

Всё хранится внутри `Parser App`, поэтому папку можно скопировать на флешку или другой компьютер вместе с базой. При закрытии программа удаляет кэши, которые браузер и окно наполняют заново (кэш страниц, кода и шейдеров Chromium в `profiles/`, такой же кэш окна в `data/webview/`, скомпилированные `.pyc`) — это около 300 МБ, и папку можно сразу архивировать. Cookies и вход на сайты, настройки, база, фотографии и журналы остаются: без cookies Авито увидел бы новый профиль и сразу показал капчу. Занятое другим процессом пропускается и освободится при следующем закрытии; дольше 25 секунд закрытие не задерживается.

| Папка | Что там |
|---|---|
| `app/` | код приложения |
| `web/` | интерфейс |
| `runtime/` | встроенный Python (создаётся `setup.bat`) |
| `browsers/` | Chromium (создаётся `setup.bat`) |
| `database/` | **вся база**: `realty.db`, фото `images/`, настройки поиска `settings.json`, резервные копии `backups/` |
| `data/` | служебное для этого компьютера (кэш окна, блокировка второго запуска) |
| `profiles/` | профили браузера и cookies для каждого сайта (не переносятся экспортом) |
| `logs/` | журналы: общий `app.log` (2 МБ × 5 файлов), `runs/` — подробный журнал каждого прогона, `snapshots/` — страницы, на которых сайт дал сбой |
| `tests/` | автоматические тесты (`tests\run_tests.bat`) |

## Как собираются данные

| Сайт | Источник данных | Способ |
|---|---|---|
| ЦИАН | JSON API поиска | HTTP; браузер как запасной вариант |
| Яндекс | `INITIAL_STATE` страницы выдачи | HTTP; браузер как запасной вариант |
| Авито | карточки страницы выдачи (из ответа сервера и со страницы после загрузки) + страница объявления (координаты, ремонт) | браузер, как человек (HTTP Авито блокирует) |

Режим `auto`: сначала быстрый HTTP с отпечатком Chrome (curl_cffi). Если сайт его блокирует, парсер переходит на стелс-Chromium (patchright) с постоянным профилем. Для Авито «авто» сразу означает браузер: быстрый HTTP-клиент Авито отклоняет всегда (кодом 429), и такой отказ клиенту с cookies браузера вызывал капчу в начале каждого прогона. Браузер запускается с песочницей Chromium и с флагом `--test-type`, поэтому над страницей нет полосы «unsupported command-line flag» (флаг `--disable-blink-features=AutomationControlled` нужен: без него сайт видит `navigator.webdriver = true`).

В браузере программа ведёт себя как человек: курсор идёт к цели по плавной дуге с разгоном и торможением, ползунок капчи тянется одним уверенным движением за полсекунды-секунду, страница просматривается сериями прокрутки с паузами, выдача Авито листается кнопкой «Следующая страница», а объявления открываются в новой вкладке кликом по карточке — выдача в первой вкладке остаётся открытой. Если ссылки на странице нет (например, после капчи), страница открывается по адресу. События мыши уходят по одному, 40–70 в секунду: быстрее Windows их браузеру не отдаёт, и движение только растянулось бы во времени.

**Капча.** На странице Авито «Доступ ограничен» сайт сам выбирает проверку: GeeTest (окно по кнопке «Пройти проверку»; новая версия страницы открывает его сама), hCaptcha (галочка) или картинку с символами; в журнале записывается, какая показана. Бывает и окно «Доступ ограничен: проблема с IP» поверх обычной выдачи (страница приходит с кодом 439) с кнопкой «Продолжить» — программа распознаёт его по самому окну на экране и проходит так же. Задание GeeTest может прийти ещё при загрузке страницы, поэтому браузер запоминает ответы GeeTest всё время. Пазл GeeTest с ползунком программа проходит сама: находит на картинке вырез под кусочек и тянет ползунок мышью, как человек, а если сайт просит пройти проверку ещё раз — проходит снова (до трёх капч подряд). Вырез ищется по трём признакам: контур кусочка лёг на перепады яркости фона, внутри выреза яркость не такая, как вокруг, и внутри видна та же картинка, что на кусочке, только затемнённая. Подсказку о высоте кусочка программа берёт и из окна GeeTest, и из самого задания, а если на вырез похоже слабо — ищет по всей высоте картинки. По каждой попытке в журнал прогона идёт строка с размерами картинки, найденным вырезом, уверенностью и тем, с какой точностью кусочек довели до места; если пазл не приняли, фон и кусочек сохраняются в `logs/snapshots` — по ним потом видно, где вырез был на самом деле. Задание и картинки берутся из того, что браузер уже получил, — лишних запросов нет. Капчу другого вида или после трёх неудачных попыток проходит человек: окно браузера появляется на экране, звучит сигнал, приходит уведомление Windows и всплывает уведомление в программе, а в журнале — предупреждение ⚠. Автопрохождение выключается в настройках («Авито: проходить пазл-капчу автоматически»). После ввода окно не нужно обновлять: программа ждёт, пока сайт сам откроет нужную страницу, и не перезагружает её (перезагрузка в этот момент вызывает новую капчу). Следующий запрос после капчи идёт с паузой 25–45 с.

На Авито объявления страницы выдачи — это её карточки. Они берутся и из HTML, который прислал сервер, и со страницы после работы её скриптов: если скрипты уберут или не дорисуют часть карточек, объявления не потеряются. В журнале прогона видно «N объявлений (в ответе сервера A, на странице B)». Данных для поисковиков (schema.org) в отфильтрованной выдаче Авито нет — они используются, только если появятся. Сервер иногда присылает на странице меньше 50 карточек (от 11 до 49); первая такая страница прогона сохраняется в `logs/snapshots/` (и как пришла от сервера, и после загрузки), чтобы разобраться, теряются ли при этом объявления. Карусели рекомендаций в результаты не попадают.

Когда капчу должен пройти человек, программа подаёт звуковой сигнал и повторяет его каждые 30 секунд, пока капча на экране. Колокольчик слева от кнопки «Запустить» выключает все звуки, включая звук уведомлений Windows, — например, на ночь; сами уведомления тогда показываются беззвучно.

Пауза Авито после ограничения IP растёт сама. После трёх сборов подряд без капчи и ограничений она понемногу возвращается к заданной в настройках, но не ниже её.

## Экраны

- **Дашборд** (открывается при запуске). Пока в базе нет ни одного объявления — на этом экране краткая инструкция: что ищем сейчас (с кнопкой в настройки), как запустить первый сбор (кнопка запускает те же сайты, что и слева) и где смотреть результат. Как только появятся объявления, экран сам сменяется сводкой. Сводка рынка: число объектов, медианы цены и цены м², новые, снятые объявления и изменения цен. Графики по каждой проверке: цены по комнатности, цена м² по зонам, движение рынка, предложение; у каждого графика есть табличный вид. Ниже — «Подешевели» (самые сильные снижения цены за период), срез по комнатности и зонам, источники, самые выгодные предложения и сводка по избранному. Наведите на заголовок блока (значок «i»), чтобы прочитать, что он показывает и как его понимать.
  - «Период графиков» (неделя, месяц, полгода, год, всё время) задаёт отрезок истории для всех графиков сразу. На графике не больше 500 точек: соседние проверки объединяются, события суммируются.
  - «Только внутри круга» пересчитывает весь дашборд только по квартирам в красном круге: показатели, графики, срез, источники, самые выгодные, подешевевшие и избранное.
- **Подборка, Таблица, Карта.** Объекты с фильтрами. Клик по карточке открывает окно объекта с графиком цен по каждому сайту. Клик по строке таблицы открывает карточку в подборке. В таблице порядок строк задаётся кликом по заголовку колонки (повторный клик — наоборот) и помнится между запусками; по умолчанию сначала недавно найденные. Выпадающей «Сортировки» в таблице нет — она осталась для подборки и карты. Цвет точки на карте — на каких сайтах найден объект: у каждого сайта свой цвет, у пары сайтов — смешанный, а объект на всех трёх сайтах — чёрная точка в белом кольце. Клик по точке показывает цены и ссылки на объявления; подсказка закрывается, как только мышь уходит с точки, а на саму подсказку перейти можно — чтобы нажать ссылку.
- **Изменения.** Новые, снятые, вернувшиеся объявления и изменения цен, плиткой на объект, с разбивкой по сайтам. Период: «последнее обновление» (что нашёл последний сбор каждого сайта; клик по уведомлению Windows открывает именно его), 6 часов, сутки, 3 дня, неделя, месяц. Первичная загрузка сайтов изменениями не считается.

## Круг на карте

Справа вверху на карте (в подборке и на вкладке «Карта») — замок. Закрытый замок: круг закреплён, карта работает как обычно. Открытый: клик по карте переносит центр круга, край круга или белая ручка тянутся мышью и меняют радиус, точки на карте в это время не нажимаются; Esc — отменить. Когда замок закрывают, программа показывает, сколько квартир войдёт в круг и выйдет из него, и после подтверждения пересчитывает зоны всех объявлений и историю графиков под новый круг. Во время сбора данных круг менять нельзя.

## Очистка данных

«Настройки → Очистка данных» убирает из статистики результаты неудачных сборов (сайт отдал не ту выдачу, парсер ошибся). Период задаётся датами включительно: пустое «с» — с самого начала, пустое «по» — по сегодня; есть быстрые кнопки. Перед удалением видно, что именно удалится. Удаляются проверки рынка (точки графиков), изменения, прогоны и записи цен за период; объявления, которые видели только в эти дни, удаляются целиком; цены возвращаются к последним до периода; снятые в эти дни объявления возвращаются в продажу и проверятся заново. «Очистить всю базу» удаляет всё, кроме настроек поиска и круга (нужно ввести слово ОЧИСТИТЬ). Перед любой очисткой база сохраняется в `database\backups`; восстановить — «Импорт…» с режимом «заменить полностью».

## Автообновление и трей

Под переключателями сайтов включается «Автообновление каждые N часов» (1, 3, 6, 8, 12 или своё число), рядом идёт обратный отсчёт. Свернутое окно уходит в трей, сбор продолжается. После сбора приходит уведомление Windows, только если на рынке что-то изменилось; клик по нему открывает «Изменения».

Запуски идут строго по расписанию, у каждого сайта свой цикл. Если сайт к очередному запуску ещё не закончил прошлый сбор (например, Авито с паузами между страницами), он не прерывается и не перезапускается: пропускает этот запуск и стартует в первый запуск после окончания. Остальные сайты запускаются как обычно. Под таймером видно, какой сайт пропустил запуск. Если сайт три сбора подряд не укладывается в шаг, там же и в журнале появляется предупреждение со средней длительностью его сбора: данные этого сайта обновляются реже, чем задано, и шаг стоит увеличить. Уведомление о сайтах, которые уже закончили, приходит не позже следующего запуска, не дожидаясь медленного сайта.

## Снятие с продажи

Отсутствие объявления в поиске само по себе ничего не значит: сайт мог не ответить, показать капчу, отдать не ту страницу. Поэтому снятие проверяется в два шага.

**1. Выдача должна быть полной и достоверной.** Иначе объявления, которых нет в поиске, не проверяются вовсе. Прогон считается неполным, если:

- любая страница не загрузилась (таймаут, ошибка сервера, капча не пройдена);
- страница посреди выдачи пришла пустой, без счётчика объявлений или с объявлениями прошлых страниц (два раза подряд);
- прочитаны не все страницы (в том числе из-за ограничения числа страниц в настройках);
- сайт не сообщил число объявлений;
- ЦИАН или Яндекс отдали меньше 95% заявленного ими числа;
- из поиска пропало больше объявлений, чем рынок реально успевает снять за прошедшее время, — это сбой, а не рынок.

Допуск на пропадание зависит от паузы между сборами. Срок жизни объявления считается экспоненциальным со средним τ, поэтому за паузу t ожидаемо снимается доля 1 − e^(−t/τ). Для каждого объявления t — время с момента, когда его последний раз видели в поиске. Допуск — ожидаемая доля плюс 20 процентных пунктов, но не меньше 25% (и 20 штук) и не больше 95%. При τ ≈ 130 дней это 25% для паузы до недели, ~40% для месяца, ~70% для трёх месяцев и 90–95% для полугода.

τ оценивается по самой базе: дни наблюдения всех объявлений делятся на подтверждённые снятия. Пока снятий мало, оценка сглаживается к 120 дням. Это ориентир по РФ: средний срок экспозиции вторички в 2025 году около 100 дней по крупным регионам (Домклик) и 110 дней по миллионникам, от 83 до 137 по городам (Яндекс Недвижимость).

Допуск влияет только на то, проверять ли пропавшие объявления. Снимаются они в любом случае только по признаку со страницы объявления.

**2. Каждое пропавшее объявление проверяется на своей странице.** Снятым оно становится только по явному признаку:

| Сайт | Снято | В продаже |
|---|---|---|
| ЦИАН | статус «снято с публикации», «удалено», «продано», «черновик», «заблокировано», «отклонено модерацией», архив; страница 404/410 | статус «опубликовано» |
| Яндекс | `active=false` или `obsolete`; страница 404/410 | `active=true` |
| Авито | `closedItem=true` (объявление закрыто); страница 404/410; ссылка уводит в каталог | `closedItem=false` |

Во всех остальных случаях (страница не загрузилась, капча, ограничение IP, непонятная страница, «на модерации») статус считается неизвестным. Объявление остаётся в продаже с отметкой «нет в поиске» и проверяется снова в следующем сборе. Капча или ограничение IP прерывают проверку остальных до следующего раза. Авито проверяет не больше 20 страниц за сбор. Причина снятия видна в подсказке на перечёркнутом объявлении. Кнопка «Перепроверить снятые» в настройках возвращает ошибочно снятые.

## Прогоны и журналы

Статус каждого сбора на вкладке «Прогоны»:

| Статус | Что значит |
|---|---|
| готово | выдача прочитана полностью, пропавшие из поиска объявления проверены на сайте |
| неполный | сбор закончился, но выдаче нельзя доверять полностью: прочитаны не все страницы, сайт отдал меньше заявленного или из поиска пропало слишком много. Новые объявления и цены записаны, снятые не проверялись |
| ошибка / блокировка | сбор прерван: сайт не ответил, пришла пустая страница, капча не пройдена. Снятые не проверялись |
| остановлен | вручную или при закрытии программы |

В таблице видно, сколько объявлений заявил сайт и сколько собрано. Кнопка ☰ в строке открывает подробный журнал прогона, его можно сохранить в файл. В журнале каждый запрос (HTTP или браузер, код ответа, время, размер), страницы выдачи, итог «заявлено / собрано / запросов / капч / ограничений IP» и проверка снятых. Если сайт показал капчу, ограничение IP, ошибку или пустую страницу, сама страница сохраняется в `logs/snapshots/`: по ней видно, что на самом деле показал сайт. Хранятся последние 300 журналов прогонов и 60 страниц.

## Объекты и дубли

Одна и та же квартира на разных сайтах (и от разных агентов на одном сайте) объединяется в один объект прямо во время сбора. Объявления считаются одним объектом, если:

- совпадают комнаты, этаж и этажность дома;
- площадь отличается не больше чем на 1 м²;
- цена отличается не больше чем на 10%;
- расстояние между точками не больше 150 м. Если у одного из объявлений нет координат (у Авито — пока не открыта страница объявления), вместо этого должен совпасть адрес «улица + дом»;
- в новостройке не различаются номера квартиры или корпуса в описании; два объявления одного сайта в новостройке объединяются только при совпадающем номере квартиры.

Объявление присоединяется к объекту, только если совпадает по характеристикам со **всеми** его объявлениями, а не с одним, чтобы цепочки похожих квартир одной планировки не склеивались. Пометка дублей Яндекса (`clusterId`) используется только для поиска кандидатов. Карточка показывает объект и ссылки на каждое его объявление с ценой.

## Фото, избранное, перенос базы

- Главное фото каждого объявления хранится в `database/images/`. Недогруженные фото повторно загружаются после каждого сбора, при запуске программы и по кнопке «Догрузить фото» в настройках.
- ♥ на карточке добавляет объект в избранное. Фильтр «Избранное» находится в панели фильтров.
- «Настройки → База данных → Экспорт…» сохраняет всю базу одним `.zip`. «Импорт…» на другом устройстве либо **объединяет** базы (новое добавляется, по общим объявлениям берётся более свежая версия), либо **заменяет** базу целиком. Перед импортом текущая база сохраняется в `database/backups/`.

## Тесты

`tests\run_tests.bat` прогоняет 55 тестов примерно за две минуты:

- сбои выгрузки не снимают объявления: таймаут, ошибка сервера, пустая страница, капча, неполная выдача, массовое пропадание с учётом паузы;
- распознавание статуса на страницах объявлений ЦИАН, Яндекса и Авито;
- выдача Авито: все объявления страницы при недорисованных карточках, карусель не собирается, адрес сохраняется из базы;
- Авито «как человек» в настоящем браузере на имитации сайта: в режиме «авто» ни одного HTTP-запроса, страницы листаются кликом (Referer и `Sec-Fetch-Site: same-origin`), объявления открываются во вкладке кликом по карточке, карточки, убранные скриптом страницы, берутся из ответа сервера, неполная страница сохраняется для разбора;
- пазл-капча: поиск выреза на картинках разного вида, в том числе когда высота кусочка подсказана неточно или подсказок две; прохождение мышью на имитации GeeTest (задание приходит при загрузке страницы, у фона и кусочка одно имя файла, кусочек едет не 1:1 с ручкой, первая попытка отклонена) с записью в журнал и сохранением картинок задания; окно, которое сайт открыл сам, не открывается повторно; окно «Доступ ограничен» поверх выдачи (код 439) проходится через «Продолжить»; капча другого вида — звук и уведомление человеку;
- расписание: пропуск занятого сайта, уведомления, предупреждение о неуспевающем сайте;
- подробный журнал и снимки страниц на настоящем HTTP-слое против локального сервера;
- очистка за период и полностью, новый круг с пересчётом зон и истории, «последнее обновление», срез «внутри круга», прореживание точек дашборда, звук;
- очистка кэшей при закрытии: кэш удаляется, cookies, настройки и база остаются, закрытие не ждёт дольше отведённого времени;
- возврат паузы Авито;
- ожидание перехода после капчи в настоящем браузере на имитации сайта: страница не перезагружается, пока человек проходит капчу, и сигнал повторяется, хотя фраза «Проверка пройдена» заранее есть в скрипте страницы.

Тесты работают на синтетических данных во временной папке: база, фото, резервные копии, настройки, профили и журналы — временные; к настоящим сайтам тесты не обращаются (браузер в тестах обрывает любой запрос не к 127.0.0.1) и звуков не издают.

## Фильтры по умолчанию

Квартира, 1–3 комнаты, от 40 м², 8–13 млн ₽, без обременения, не доля, не аукцион, с ремонтом. Меняются на вкладке «Настройки». Отсеянные объявления не удаляются: их можно посмотреть с фильтром «Статус → отсеянные» вместе с причиной отсева.
