RealtyWatch — анализ рынка квартир в Ялте (ЦИАН, Авито, Яндекс Недвижимость)
==========================================================================

КАК ЗАПУСТИТЬ НА НОВОМ КОМПЬЮТЕРЕ
1. Распакуйте архив в любую папку (можно на флешку). Путь лучше без длинных вложенных папок.
2. Запустите RealtyWatch.exe.
3. При первом запуске откроется окно установки: программа сама скачает из интернета
   Python 3.12, библиотеки и браузер Chromium (скачивается около 350 МБ, на диске около 700 МБ,
   обычно 2–10 минут). Нужен интернет.
   Всё ставится только внутрь этой папки — в систему ничего не устанавливается.
4. После установки откроется окно программы. Дальше запуск — мгновенный.

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
- Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
- Если установка прервалась (пропал интернет) — просто запустите RealtyWatch.exe ещё раз:
  уже скачанное пропускается. Полная переустановка компонентов — setup.bat.
- Нужен WebView2 Runtime — в Windows 10/11 он обычно уже есть.
  Если окно не открывается: https://developer.microsoft.com/microsoft-edge/webview2/
- Запасной способ запуска — start.bat.

ПЕРЕНОС ДАННЫХ
Вся база — в папке database. Перенести на другой компьютер:
«Настройки → База данных → Экспорт…» здесь, «Импорт…» там (или скопировать папку целиком).

Подробное описание — README.md.
