# RealtyWatch для macOS

Форк Windows-версии (она лежит в `RealtyWatch_Win/` и здесь не меняется). Собирается в обычное
приложение `RealtyWatch.app`: иконка в «Программах», двойной клик, окно — как у любой маковской программы.

Что внутри то же самое: сбор объявлений с ЦИАН, Авито и Яндекс Недвижимости, объединение дублей,
красный круг на карте, история цен, расписание, автопрохождение пазл-капчи Авито.

## Как собрать и запустить на Mac

```bash
cd RealtyWatch_Mac
./build_app.sh            # соберёт dist/RealtyWatch.app
open dist                 # перетащите приложение в «Программы»
```

Первый запуск сам доставит среду выполнения (~350 МБ) в `~/Library/Application Support/RealtyWatch`:
Python 3.12, библиотеки и Chromium. Это видно в окне Терминала, после «готово» программа откроется сама.
Дальше запуск мгновенный.

Для разработки сборка не нужна — `./start.command` (или `bash bin/launch.sh`) запускает то же самое
из папки с исходниками. Тесты — `tests/run_tests.command`.

## Где что лежит

| Где | Что |
|---|---|
| `RealtyWatch.app` | только код: `app/`, `web/`, `assets/`, `bin/` — около 2 МБ |
| `~/Library/Application Support/RealtyWatch/` | всё, что программа пишет |
| `…/database/` | `realty.db`, фотографии, `settings.json` — это и есть база, её переносят целиком |
| `…/runtime/`, `…/browsers/` | Python и Chromium, их приносит `bin/bootstrap.sh` |
| `…/profiles/` | профили браузера и cookies, привязаны к этому компьютеру |
| `…/logs/` | журналы прогонов |

Бандл не пишет внутрь себя — так принято на macOS и так не ломается подпись. Рабочую папку можно
задать переменной `RW_HOME` (например, чтобы держать всё на внешнем диске).

## Отличия от Windows-версии

- **Значка в строке меню нет.** На macOS и окно (pywebview), и значок (pystray) требуют главный
  цикл приложения — вместе они не уживаются. Уведомления приходят обычные, системные.
- **Режим «скрытое окно» браузера показывает окно.** macOS не даёт увести окно за край экрана:
  оно открывается в дальнем углу и не выходит вперёд. Если мешает — в настройках есть «без окна».
- **Звук капчи** — системный звук macOS (`Glass`), частоты задать нельзя.
- **Иконку и имя** приложение берёт из `Info.plist` бандла, а не из кода.

## Передача другому человеку

Приложение не подписано Apple ID разработчика ($99 в год), поэтому macOS встречает скачанное
приложение предупреждением. Варианты, по возрастанию удобства:

1. **Собрать на том же Mac** (`./build_app.sh`) — метки карантина нет, открывается сразу. Лучший способ.
2. **Переслать `RealtyWatch.dmg`** — его делает `./build_dmg.sh`, и он же лежит артефактом
   каждого прогона на GitHub. Получатель открывает образ двойным кликом, перетаскивает
   приложение в «Программы» и один раз разрешает запуск: «Системные настройки» →
   «Конфиденциальность и безопасность» → «Открыть всё равно». В macOS 15 Sequoia и новее
   обхода через правый клик больше нет; кому привычен Терминал, тому быстрее
   `xattr -dr com.apple.quarantine /Applications/RealtyWatch.app`.
3. **Купить Developer ID и нотаризовать** — тогда двойной клик работает у всех без оговорок.

Подробный разбор вариантов упаковки и подписи — в [PORT.md](PORT.md).

## Проверка на настоящем Mac

`.github/workflows/mac.yml` прогоняет на раннере GitHub (настоящее железо Apple, Apple Silicon)
всю цепочку: доставку среды, тесты, сборку `.app` и запуск сервера. Готовое приложение остаётся
артефактом сборки.
