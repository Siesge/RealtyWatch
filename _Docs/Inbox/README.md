## Что ещё присылал владелец

Искали по всем пяти стенограммам проекта: в каждой строке разбирался `message.content` и
считались блоки `type == "image"`. Кроме снимка выше нашлись два файла в стенограммах
Windows-сессии:

| Где | Когда | Что |
|---|---|---|
| `2b9c3d60-….jsonl`, строка 3 | 31 октября, 17:06 | jpeg, 214 302 байта |
| `9b67bc2b-….jsonl`, строка 834 | 2 ноября, 08:37 | webp, 155 606 байт |

Ни один из них не совпадает с `GeoZone_v1.jpg` в корне репозитория (575 348 байт), то есть это не
копии карты зоны. Чем они являются, опознаёт Windows-сессия — строки ждут своих описаний. Оговорка
та же: если на снимке личное, сюда кладётся строка, а не файл.

Когда владелец передаст файл, его место здесь, и в этот список дописывается строка: что это,
откуда пришло и где используется. Без такой строки через месяц никто не отличит присланный
материал от случайно забытого файла.
