# Список изменений

Задачи, отложенные на будущее. Новые пункты добавляются в конец.

## 1. История цен в карточке и окно с графиком

- Если цена квартиры изменилась, в карточке показывается новая цена, а рядом прежняя, перечёркнутая.
- Клик по карточке открывает окно объекта с графиком цен за всё время с первого сканирования, отдельной линией для каждого агрегатора (ЦИАН, Авито, Яндекс).

Что уже есть: изменения цены записываются в таблицу `price_history` для каждого объявления с первого сбора. Сейчас в карточке показывается только значок «↓/↑ N млн».
