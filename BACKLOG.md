# Список изменений

Задачи, отложенные на будущее. Новые пункты добавляются в конец.

## 1. История цен в карточке и окно с графиком

- Если цена квартиры изменилась, в карточке показывается новая цена, а рядом прежняя, перечёркнутая.
- Клик по карточке открывает окно объекта с графиком цен за всё время с первого сканирования, отдельной линией для каждого агрегатора (ЦИАН, Авито, Яндекс).

Что уже есть: изменения цены записываются в таблицу `price_history` для каждого объявления с первого сбора. Сейчас в карточке показывается только значок «↓/↑ N млн».

## 2. Диагностический лог парсинга

Сейчас `logs/app.log` пишет только «страница N: M объявлений» и итог прогона. Этого мало, чтобы разобраться в сбое. Нужно:

- по каждому запросу записывать адрес, способ (HTTP или браузер), код ответа, время загрузки, число найденных и уникальных объявлений, повторы;
- при сбое, капче или пустой странице сохранять HTML этой страницы в `logs/snapshots/` с привязкой к прогону;
- проверять каждый прогон на признаки обрыва: собрано меньше, чем заявил сайт; непривычно много «снятых» объявлений; страница без объявлений посреди выдачи. Предупреждать о них в журнале и в уведомлении;
- в интерфейсе: у каждого прогона на вкладке «Прогоны» кнопка с подробным логом и экспорт лога в файл, чтобы его можно было прислать;
- ротация логов, чтобы они не разрастались;
- прогоны, прерванные закрытием программы или падением, при следующем запуске помечать как «прерван». Сейчас прогоны 3 и 4 Авито навсегда остались в статусе «идёт».
